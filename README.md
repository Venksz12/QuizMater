# 🧠 QuizMater

QuizMater is a full-stack quiz management platform that enables users to create, manage, and take quizzes through an intuitive and responsive interface. The application is designed to simplify quiz creation while providing an engaging experience for participants.

## 🚀 Features

- 🔐 User Authentication
- 📝 Create, Edit, and Delete Quizzes
- ❓ Multiple Choice Questions Support
- 📊 Instant Score Evaluation
- 📱 Responsive User Interface
- ⚡ Fast and User-Friendly Experience

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Venksz12/QuizMater.git
```

Navigate to the project folder

```bash
cd QuizMater
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

Linux/Mac

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000/
```
